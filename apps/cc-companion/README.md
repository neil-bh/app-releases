# CC Companion → Claude Control for Android

<img src="logo.png" width="96" align="right" alt="">

**This app is now [Claude Control for Android](../claude-control-android/README.md)**: the companion was merged into
the main app, so there is one Android APK. Download it from there.

This folder is only the old update feed (`latest.json`), kept so a phone still running the old CC Companion can find
its way to the new app. Every release of Claude Control for Android updates it too, pointing at the same file.
Earlier releases `cc-companion-v…` stay on the [releases page](https://github.com/neil-bh/app-releases/releases?q=cc-companion&expanded=true).
